# Handling New Requirements During Implementation

## Problem/Feature Description

You are an AI developer agent using the spec-workflow skill. You are implementing task 2 of `specs/0003-search/`. The spec status is "Implementing" (frozen). During implementation, you realize the search feature would benefit from adding full-text indexing, which was not in the original spec requirements. The user says: "Oh good idea, add full-text indexing too while you're at it."

Describe how you respond to this request. What do you do? What do you NOT do? Be specific about what actions you take regarding the spec, the current task, and the new requirement.

## Output Specification

Describe your response to the user's request, covering:
- Whether you modify the spec
- Where you record the new requirement
- Whether you expand the current task's scope
- What you tell the user
