# Clean Up the Wording of a Statistics Guide

## Problem Description

A data team wrote `inputs/stats-guide.md` for analysts who are new
to the company. A reviewer said parts of it sound like a chatbot
wrote them and asked for the wording to be cleaned up.

The guide is short and mostly correct. Its statistical terms must
stay exact, because analysts look them up.

## Output Specification

Edit `inputs/stats-guide.md` in place. Then write `summary.md`
listing what you changed, and each wording you considered but kept,
with the reason.
