# Watch list

Words and phrases that make writing sound inflated, padded or
machine-written. `scripts/check.py` reads the backticked terms on
each `- ` line under **Words** and **Phrases**, so keep one entry per
line in that form. The text after `→` is the plain alternative.

A term is a signal, not a verdict. Keep it when it is the precise
word, such as `robust` for a statistical method or `key` for a
cryptographic key.

## Words

Words match with common endings (`delve` also finds `delves`).

- `actually` → (delete)
- `additionally` → also
- `bolster` → support
- `comprehensive` → (say what it covers)
- `crucial` → important
- `delve` → look at
- `effortlessly` → (delete)
- `empower` → let, help
- `enhance` → improve
- `facilitate` → help, make possible
- `foster` → help, support
- `functionality` → feature, function
- `furthermore`, `moreover` → also
- `garner` → get
- `interplay` → (say how the two affect each other)
- `intricate` → complex
- `landscape` → field (when used for an abstract area)
- `leverage`, `utilize` → use
- `meticulous`, `meticulously` → careful, carefully
- `pivotal` → important
- `powerful` → (say what it does)
- `robust` → (name the property), unless it is a technical term
- `seamless`, `seamlessly` → (delete)
- `showcase` → show
- `simply` → (delete)
- `streamline` → simplify
- `tapestry` → (delete)
- `testament` → shows
- `underscore` → show (as a verb)
- `unconditionally` → (delete), or say the condition that never applies
- `vibrant` → (delete)

## Phrases

- `in order to` → to
- `prior to` → before
- `due to the fact that` → because
- `in the event that` → if
- `when it comes to` → for
- `allows you to`, `enables you to` → you can
- `is designed to` → (say what it does)
- `by design` → (delete)
- `out of the box` → by default
- `under the hood` → internally
- `serves as`, `stands as` → is
- `plays a key role` → (say what it does)
- `a testament to` → shows
- `it is worth noting`, `it's worth noting` → (delete)
- `it is important to note`, `it's important to note` → (delete)
- `that being said` → but
- `in conclusion`, `in summary`, `at the end of the day` → (delete)
- `not just`, `not only` → (state the point directly)
- `let's dive in`, `let's explore`, `let's break this down` → (delete)
- `here's what you need to know`, `here's the thing` → (delete)
- `without further ado` → (delete)
- `to be clear`, `don't get me wrong` → (delete)
- `i hope this helps`, `great question`, `let me know if` → (delete)
