# Challenge the Database Decomposition Plan

## Problem Description

The platform team is about to kick off a major database decomposition project. The plan (see `inputs/migration-plan.md`) describes splitting a shared PostgreSQL database into domain-owned databases for each microservice over two sprints.

Before the project is formally started and resources are committed, the CTO has asked someone to put it through a rigorous challenge. Nothing is off-limits — scope, sequencing, risks, assumptions, missing steps, and anything else that could cause the project to fail or stall in production.

Work through the plan systematically and challenge every decision you encounter.

## Output Specification

Write your full challenge analysis to a file called `challenge-report.md`. The report should document all the decisions you examined, your view on each, and a structured summary at the end.

Do not modify `inputs/migration-plan.md`.
