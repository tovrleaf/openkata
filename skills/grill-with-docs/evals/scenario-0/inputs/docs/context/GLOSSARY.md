# Glossary

Domain language for the e-commerce order fulfillment platform.

## Language

**Order**:
A customer's confirmed intent to purchase one or more items, assigned a unique ID.
_Avoid_: Purchase, transaction, request

**Customer**:
A registered user who places orders on the platform.
_Avoid_: User, buyer, client, account

**Checkout**:
The multi-step UI flow where a customer provides payment and shipping details before an Order is created.
_Avoid_: Cart, purchase flow, buy flow
